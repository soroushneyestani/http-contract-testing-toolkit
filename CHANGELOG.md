# Changelog

## 0.1.0

- Preserve version 1 TSV declaration comparison and add optional response fields.
- Verify one real local HTTP GET and inspect the provider's actual status and JSON field types.
- Demonstrate baseline success, a required-field break, additive compatibility and recovery with deterministic synthetic provider states.
- Report stable incompatibilities and differentiate usage or transport errors by exit code.
- Run JUnit and upload XML and human-readable demonstration evidence in CI.
- Provide reproducible checksummed source packaging, technical guides and the original MIT license.
