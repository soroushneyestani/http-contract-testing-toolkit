# کپشن اینستاگرام

پاسخ `200 OK` هم می‌تواند مصرف‌کنندهٔ API را از کار بیندازد.

نسخهٔ `0.1.0` ابزار Contract Testing Toolkit را با Java ساختم تا این وضعیت را در یک نمونهٔ قابل تکرار نشان دهم. ابزار هم قراردادهای اعلام‌شده را مقایسه می‌کند و هم JSON دریافتی از یک ارائه‌دهندهٔ HTTP محلی و ساختگی را می‌سنجد.

دمو یک قرارداد را با پاسخ پایه، تغییر ناسازگار، تغییر افزایشی و پاسخ بازیابی‌شده آزمایش می‌کند. تغییر نوع شناسه و حذف قیمت الزامی باعث شکست آزمون می‌شود. اضافه کردن فیلدی که مصرف‌کننده به آن نیاز ندارد، سازگاری را حفظ می‌کند.

کدهای خروجی CLI و گزارش XML آزمون‌های JUnit ثبت نتیجه را در گردش‌کار خودکار ممکن می‌کنند.
