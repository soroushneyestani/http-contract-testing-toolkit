# Contract Testing Toolkit 0.1.0

This initial version compares versioned consumer and provider declarations and checks the observed status and top-level fields from a local JSON API. The download contains Java source, tests, synthetic fixtures, documentation and licensing notices.

From the extracted source, run `pwsh -NoProfile -File scripts/verify.ps1` with a supported JDK. The script compiles, runs JUnit, checks the two declaration examples and demonstrates baseline, breaking, additive and recovery behavior over real loopback HTTP. It writes JUnit XML and `observed-demo.txt` under the printed report directory. [Quick start](../../README.md) · [Contract examples](../SPEC.md) · [Verification](../RELEASE_EVIDENCE.md)

Compare the source ZIP's SHA-256 against the accompanying `SHA256SUMS.txt`. The ZIP comment records the source commit. The packager rebuilds this archive from Git file bytes and verifies every entry.

The first version supports one TSV HTTP interaction and top-level type checks. Observed-response verification is limited to GET on IPv4 loopback with an explicit port and a single UTF-8 JSON object. Nested values are checked for JSON syntax and top-level shape. Value matching, schema evolution guarantees across all provider states, Broker and Pact artifact interoperability are outside this contract.
